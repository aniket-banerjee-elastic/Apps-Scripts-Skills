This zip is an Agent Skills package (SKILL.md + references/assets/scripts).

Cursor
------
1. Unzip this archive.
2. Copy the folder "apps-script-dashboard-validation" into one of:
   - Personal (all projects):  ~/.cursor/skills/
   - Project-only:            <repo>/.cursor/skills/
3. Restart Cursor or open a new agent chat. The skill loads from SKILL.md.
